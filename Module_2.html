Markov Decision Processes

Reinforcement learning is learning by interaction: an agent acts, the world responds with a new state and a reward, and the agent improves. This module introduces the terminology and the formal framework, the finite Markov decision process, that the rest of the course builds on. Reinforcement learning terminology

Reinforcement learning (RL). The science of decision making. An agent senses an environment, takes actions that change its state, and receives rewards. It learns strategies that maximize long-term reward, even when it starts without a complete model of the environment.

RL suits any problem where sequences of decisions matter: chess, mazes, path planning, robot arms, sweeper robots. Formally, it addresses a goal-directed agent interacting with an uncertain environment and using its experience to improve over time, as a chess player refines the intuition used to evaluate positions.

ParadigmLearns fromGoal
SupervisedLabelled examples from an external supervisorPredict labels, classify
UnsupervisedUnlabelled dataFind hidden structure, e.g. K-means
ReinforcementInteraction and a reward signalMaximize cumulative reward

Main characteristics

  • No expert supervision during training.
  • The environment is usually stochastic, and the model of it can be incomplete.
  • Feedback can be delayed or partial: an action affects the next situation and all later rewards.
  • Exploration versus exploitation. The agent must try a variety of actions, yet favor those that have worked. This trade-off arises only in RL.

Three historical threads

RL merges trial-and-error learning (from the psychology of animal learning), optimal control solved with dynamic programming (Bellman, 1950s: break a problem into subproblems, solve each once, store the results), and temporal-difference learning.

3

Elements of RL

An RL system has four main elements.

1. Policy

What action to take in the current state. It may be a lookup table, a search process, or stochastic, giving a probability to each action.

2. Reward signal

The immediate, short-term outcome of an action, positive or negative. It defines the goal: maximize the total reward received over the long run.

3. Value function

The total reward an agent can expect to accumulate from a state onward. Rewards say what is good now; values say what is good in the long run. A state with a low immediate reward can have a high value because it leads to high-reward states. Without rewards there would be no values, and values are estimated only to obtain more reward. The agent should choose actions that bring the highest value, not the highest reward, though values are much harder to determine.

4. Model of the environment

It mimics the environment: given a state and action, it predicts the next state and reward. Models are used for planning. Methods that use one are model-based; simpler model-free methods learn by trial and error.

4

Scope and limitations

Scope

RL is used in computer science, engineering, mathematics, economics, neuroscience and psychology, in applications from resource allocation in operating systems to unmanned helicopter control. It is especially useful in robotics, where the best action in each state is not known in advance.

The simplest algorithms are tabular: the state and action spaces are small enough for value functions to be stored as tables, so exact solutions are often possible. There are three classes:

MethodNeeds a model?Trade-off
Dynamic programmingYes, complete and accurateWell developed mathematically
Monte CarloNoConceptually simple, but waits for an episode to end
Temporal-differenceNoFully incremental, but harder to analyze

Limitations

  • Learning by trial and error can need very many interactions.
  • Rewards are hard to design: a poor choice teaches the wrong behavior, and some tasks (grasping) have no obvious reward.
  • Tables become impossible when the number of states is very large, so approximation is needed.
  • Delayed rewards make it hard to decide which earlier action deserves credit.
  • Dynamic programming requires a model, which is often unavailable.

The lecture slides do not list limitations; the list above gives the commonly cited ones.

5

The agent–environment interface

A Markov decision process (MDP) formalizes the interaction. Time advances in steps \(t=0,1,2,\dots\). At each step the agent observes the state \(S_t\), chooses an action \(A_t\), and the environment answers with a reward \(R_{t+1}\) and a next state \(S_{t+1}\). The interaction produces a trajectory

$$S_0,\,A_0,\,R_1,\,S_1,\,A_1,\,R_2,\,S_2,\dots$$
Dynamics of a finite MDP. The sets of states, actions and rewards are finite, and the environment is described by $$p(s',r\mid s,a)=P(S_{t+1}=s',\,R_{t+1}=r\mid S_t=s,\,A_t=a),\qquad \sum_{s',r}p(s',r\mid s,a)=1$$

This is a conditional distribution of the kind reviewed in Module 1. The Markov property says the next state and reward depend only on the current state and action, not on the earlier history. The state must therefore contain whatever information from the past matters. The transition probability of the slides is obtained by summing over rewards: \(p(s'\mid s,a)=\sum_r p(s',r\mid s,a)\).

6

Goals and rewards

Reward hypothesis. Every goal can be expressed as the maximization of the expected cumulative sum of a scalar reward signal.

The reward tells the agent what to achieve, not how. Reward winning a game, not capturing pieces, or the agent may learn to hoard pieces and lose. Rewards define good and bad events: reaching a goal earns a positive reward, a hazard a negative one, and an ordinary step can carry a small cost that encourages finishing quickly, as in the gridworld below.

7

Returns and episodes

An episode is the whole sequence of states and actions from a start until a terminal state at time \(T\). Tasks that never end are continuing. The agent maximizes the expected return, the discounted sum of future rewards:

Return. $$G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1},\qquad G_t=R_{t+1}+\gamma G_{t+1}$$ The discount factor \(0\le\gamma\le1\) makes distant rewards count less. A small \(\gamma\) is short-sighted, a \(\gamma\) near 1 far-sighted. For continuing tasks \(\gamma\lt1\) keeps the sum finite.

The lecture slides index rewards from \(r_t\); here they start at \(R_{t+1}\). The idea is identical.

Example — computing a return

With \(\gamma=0.5\), suppose the rewards after time \(t\) are \(R_{t+1}=1\), \(R_{t+2}=0\), \(R_{t+3}=2\), and the episode then ends.

$$G_t=1+0.5(0)+0.5^2(2)=1.5$$

Check with the recursion: \(G_{t+1}=0+0.5(2)=1\), so \(G_t=1+0.5(1)=1.5\).

8

Policies and value functions

Policy. A mapping from states to actions, deterministic or stochastic: $$a=\pi(s)\qquad\text{or}\qquad\pi(a\mid s)=P(A_t=a\mid S_t=s)$$

A stochastic policy is a conditional PMF over actions. Value functions measure how good it is to follow a policy \(\pi\):

State-value and action-value functions. $$v_\pi(s)=E_\pi[G_t\mid S_t=s]\qquad q_\pi(s,a)=E_\pi[G_t\mid S_t=s,\,A_t=a]$$ where \(q_\pi\) is the expected return after taking \(a\) in \(s\) and following \(\pi\) afterwards (the Q-value). They are related by \(v_\pi(s)=\sum_a\pi(a\mid s)\,q_\pi(s,a)\).

Values satisfy the Bellman expectation equation, which expresses the value of a state through the values of its successors:

$$v_\pi(s)=\sum_a\pi(a\mid s)\sum_{s',r}p(s',r\mid s,a)\big[r+\gamma\,v_\pi(s')\big]$$

Example — estimating a value by averaging

Because \(v_\pi(s)\) is an expectation, it can be estimated by running \(\pi\) from state \(s\) several times and averaging the returns: \(v_\pi(s)\approx\frac1N\sum_i G_i\). If three episodes from \(s\) give returns 4, 6 and 5, then \(v_\pi(s)\approx\frac{4+6+5}{3}=5\).

Two tasks follow. Prediction has a fixed policy and evaluates it by estimating \(v_\pi\) or \(q_\pi\): "evaluate the future". Control does not know the policy and searches for the one that collects the most reward: "optimize the future".

9

Optimal policies and value functions

Optimality. A policy \(\pi_*\) is optimal if its value is at least that of every other policy in every state. All optimal policies share the same optimal value functions: $$v_*(s)=\max_\pi v_\pi(s)\qquad q_*(s,a)=\max_\pi q_\pi(s,a)$$

Knowing \(q_*\) makes acting optimally easy: in each state choose the action with the highest Q-value,

$$\pi_*(s)=\arg\max_a q_*(s,a)$$

The optimal values satisfy the Bellman optimality equation, which dynamic programming solves when the model is known:

$$v_*(s)=\max_a\sum_{s',r}p(s',r\mid s,a)\big[r+\gamma\,v_*(s')\big]$$

The optimal policy depends on the rewards. The lab below shows the same grid producing very different optimal behavior as the step reward changes.

Gridworld lab

This is the motion-planning example from the lecture: a 4×3 grid with a wall, and terminal states worth +1 and −1. A move goes in the intended direction with probability 0.8 and slips to each side with probability 0.1. Every non-terminal step earns the reward \(R(s)\), which you can change. The optimal policy is computed by value iteration with \(\gamma=1\).

Self-check

Why choose the action with the highest value rather than the highest reward?

Reward is immediate, while value is the expected total reward from that point on. A low-reward step can lead to high-reward states.

What does the Markov property say?

The next state and reward depend only on the current state and action, not on how the agent arrived there.

What does the discount factor \(\gamma\) control?

How much future rewards count. Small \(\gamma\) is short-sighted, \(\gamma\) near 1 is far-sighted, and \(\gamma\lt1\) keeps returns finite in continuing tasks.

Prediction versus control?

Prediction estimates the value of a given policy. Control finds the optimal policy.

Given \(q_*\), how do you act optimally?

In each state choose the action with the highest Q-value: \(\pi_*(s)=\arg\max_a q_*(s,a)\).
