Families of RL

In reinforcement learning (RL) an agent learns to decide by interacting with an environment and receiving rewards or penalties. The goal is a policy that maximizes expected cumulative reward.

Model-based RL

The agent uses a model of the environment (state transitions and expected rewards) to predict what follows an action, then plans and improves its policy. The model may be given or learned. Example: a robot learns how its movements change its position and plans a route.

Model-free RL

The agent learns directly from experience, with no model of the environment. TD learning is a core technique here. Example: a game agent learns which moves work by playing many games.

Three approaches in model-free RL

  • Value-based: estimate values of states or state-action pairs and act on them (Q-learning, SARSA, Expected SARSA).
  • Policy-based: learn the policy directly by adjusting its parameters (REINFORCE).
  • Actor-critic: an actor chooses actions while a critic evaluates them and gives feedback (A2C).

TD learning and key terms

Temporal-difference learning. A model-free method that updates value estimates from the reward received plus the estimated value of the next state. It combines Monte Carlo (learning from experience) with dynamic programming (bootstrapping). Unlike Monte Carlo, it does not wait for the episode to finish.

Overview

TD learning is a model-free method for estimating an agent’s expected future rewards through interaction with its environment. It combines ideas from Monte Carlo (MC) methods and dynamic programming (DP):

  • Like MC, it learns directly from experience without a model of the environment.
  • Like DP, it bootstraps: it updates a value estimate using another estimated value.
  • Unlike MC, one-step TD updates after each step without waiting for the episode to finish.
  • It can be used for both policy evaluation (prediction) and policy improvement (control).

TD learning is commonly used in value-based reinforcement learning methods such as TD(0), SARSA and Q-learning. The main difference between MC, DP and TD methods lies in how their value estimates are updated.

Working of TD learning

The agent observes a state, takes an action, receives a reward and moves to the next state. It then updates its earlier value estimate using the new information.

Basic idea

The agent learns by comparing its previous estimate with a new estimate obtained after receiving a reward. Consider a robot learning to reach a destination:

  1. The robot is in the current state \(S_t\).
  2. It takes an action and receives reward \(R_{t+1}\).
  3. It moves to the next state \(S_{t+1}\).
  4. It uses the reward and the estimated next-state value to update its current-state value.

Temporal-difference error

The TD error measures the difference between the new one-step target and the current estimated value.

$$\boxed{\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)}$$ Where:
  • \(\delta_t\) = temporal-difference error
  • \(R_{t+1}\) = reward received after taking an action
  • \(\gamma\) = discount factor (between 0 and 1)
  • \(V(S_t)\) = current state’s estimated value
  • \(V(S_{t+1})\) = next state’s estimated value

The TD(0) value update is

$$\boxed{V(S_t)\leftarrow V(S_t)+\alpha\,\delta_t}$$ where \(\alpha\) is the learning rate.

Numerical example

Suppose:

  • Current state value = 10
  • Reward received = 5
  • Next-state value = 12
  • Discount factor = 0.9
  • Learning rate = 0.1

TD error:

$$\delta_t=5+0.9(12)-10=5.8$$

Updated value:

$$V_{\text{new}}(S_t)=10+0.1(5.8)$$ $$\boxed{V_{\text{new}}(S_t)=10.58}$$

Therefore, the agent updates its estimated state value from 10 to 10.58.

Example: predicting journey time

Consider a person travelling home and estimating how much time is left to reach the destination.

  • Monte Carlo method: the person waits until reaching home, then compares the predicted journey time with the actual journey time and updates the estimate.
  • TD learning: the person updates the estimate at each stage of the journey, using the time already spent travelling and the new estimate of the remaining time.

For example, if the person originally predicts 30 minutes but later receives information suggesting the journey will take longer, the estimate can be adjusted immediately, without waiting to reach home. Thus, TD learning updates predictions step by step, based on the difference between the old estimate and the new one-step target.

Generalized Policy Iteration (GPI) in TD Learning

Generalized Policy Iteration involves two interacting processes:

  • Policy Evaluation (Prediction): Estimate how good the current policy is using a value function.
  • Policy Improvement (Control): Improve the policy by selecting actions with higher estimated values.

These processes are repeated so that the agent gradually learns better behavior.

TD prediction methods perform policy evaluation, while TD control algorithms such as SARSA and Q-learning combine value estimation with policy improvement.

TD(0) prediction

TD(0) is the one-step method for estimating \(V^\pi(s)\) under a given policy \(\pi\). It is called a one-step TD method because it uses one observed transition before updating the value function.

TD prediction

TD prediction is the process of estimating the state-value function \(V(s)\) for a given policy using observed rewards and estimated next-state values.

  • Monte Carlo methods wait until the episode ends before updating state values using the complete return.
  • TD(0) updates the state value after each transition without waiting for the episode to finish.
  • TD(0) uses the immediate reward and the estimated value of the next state.
  • This process is called one-step bootstrapping.
TD(0) update in one line. $$\boxed{V(S_t)\leftarrow V(S_t)+\alpha\left[R_{t+1}+\gamma V(S_{t+1})-V(S_t)\right]}$$ The bracketed term is the TD error \(\delta_t\): the difference between the new one-step TD target and the current value estimate.
TD(0) update. $$\boxed{V(S_t)\leftarrow V(S_t)+\alpha\,\delta_t}$$ where the TD error is $$\boxed{\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)}$$ Here:
  • \(V(S_t)\): current estimated value.
  • \(R_{t+1}\): immediate reward.
  • \(V(S_{t+1})\): estimated value of the next state.
  • \(\alpha\): learning rate.
  • \(\gamma\): discount factor.
  • \(\delta_t\): temporal-difference error.
The TD target is \(R_{t+1}+\gamma V(S_{t+1})\). For a terminal state, the next-state value is taken as zero.

Example: one TD(0) update

Let \(V(S_t)=10\), \(R_{t+1}=5\), \(V(S_{t+1})=12\), \(\alpha=0.1\), \(\gamma=0.9\).

First, calculate the TD target:

$$5+0.9(12)=15.8$$

Then calculate the TD error:

$$\delta_t=15.8-10=5.8$$

Update the value:

$$\boxed{V_{\text{new}}(S_t)=10+0.1(5.8)=10.58}$$

Therefore, the estimated value increases from 10 to 10.58.

  • Lower open circle: the next state \(S_{t+1}\).
  • Arrow: the sampled transition from the current state to the next state.
  • Backup: the reward and the estimated value of the next state are used to update the current state’s value.
$$\boxed{\text{TD Target}=R_{t+1}+\gamma V(S_{t+1})}$$ This is called a one-step backup because TD(0) looks one transition ahead before updating the current value estimate.

Key characteristics of TD(0)

  1. Single-step update: updates the value of the current state after each transition.
  2. Model-free: does not require knowledge of environment transition probabilities.
  3. Online learning: updates estimates after each step.
  4. Bootstrapping: uses the next state’s estimated value to update the current state.
  5. Sampling: learns from actual transitions experienced by the agent.
  6. Policy evaluation: estimates the value function for a given policy.
  7. One-step method: uses one observed reward before bootstrapping.
  8. Computationally efficient: requires relatively simple calculations and little memory.

Limitations of TD(0)

  1. Bootstrapping bias: updates depend on estimated next-state values, which may initially be inaccurate.
  2. Learning rate sensitivity: an inappropriate learning rate may cause slow or unstable learning.
  3. Slow reward propagation: because TD(0) looks only one step ahead, information from distant rewards may take many updates to reach earlier states.
  4. Convergence conditions: guaranteed convergence requires suitable assumptions, such as sufficient state visits and appropriate learning rates in tabular prediction.

Advantages of TD Learning

  1. Online learning: Can update estimates immediately after each step.
  2. No environment model: Learns directly from interactions.
  3. Faster feedback: Does not need to wait until the end of an episode.
  4. Memory efficient: One-step TD requires only the current transition and value estimates.
  5. Suitable for continuous tasks: Can learn in environments without natural episode endings.

TD learning for continuing tasks

TD learning is particularly useful for continuing tasks, where the interaction between an agent and its environment does not have a definite ending.

  • No need for complete episodes: unlike conventional Monte Carlo methods, TD learning can update estimates without waiting for an episode to finish.
  • Continuous learning: the agent updates its value estimates after every step.
  • Real-time adaptation: the agent can improve its predictions as new information becomes available.

Example

A robot operating continuously in a factory can learn from its actions without stopping or completing an episode.

Optimality of TD(0)

  • In a finite Markov reward process, with a fixed policy, suitably diminishing learning rates and enough visits, tabular TD(0) converges to the true \(V^\pi\).
  • It is not guaranteed to be most accurate after a limited number of samples.
  • Versus Monte Carlo: often lower variance, but bootstrapping can add bias.
  • With function approximation, convergence needs extra conditions.

TD(0) evaluates a policy. It does not by itself find an optimal one.

Conclusion: TD(0) combines the experience-based learning of Monte Carlo methods with the bootstrapping approach of Dynamic Programming. It estimates state values after every transition, making it useful for online policy evaluation in reinforcement learning.

TD(1) algorithm

Definition. TD(1) is a special case of TD(\(\lambda\)) learning where \(\lambda=1\). It uses eligibility traces to update previously visited states based on their contribution to the current experience.

Eligibility traces keep track of recently visited states and determine how much each state should be updated.

Key features of TD(1)

  1. Eligibility traces: maintains a record of previously visited states to determine how much each state should be updated.
  2. Credit assignment: updates previously visited states according to their eligibility traces, allowing rewards to influence earlier states.
  3. Monte Carlo relationship: in episodic tasks, TD(1) is closely related to Monte Carlo learning because it uses information corresponding to complete episode returns.
  4. Online updates: in its backward-view implementation, TD(1) can update state values at every step rather than waiting until the episode ends.
  5. Suitable for episodic tasks: particularly useful when learning from sequences of states and rewards.

Working principle

  1. The agent visits a state and performs an action.
  2. It receives a reward and calculates the TD error.
  3. An eligibility trace is maintained for each state.
  4. Recently visited states receive greater credit than states visited further in the past.
  5. The TD error is used to update the values of states according to their eligibility traces.

Eligibility trace equation

For a simple accumulating-trace implementation:

$$e_t(s)=\gamma\lambda e_{t-1}(s)+\mathbb{I}(S_t=s)$$

For TD(1), \(\lambda=1\):

$$\boxed{e_t(s)=\gamma e_{t-1}(s)+\mathbb{I}(S_t=s)}$$ Where:
  • \(e_t(s)\): eligibility trace of state \(s\).
  • \(\gamma\): discount factor.
  • \(\mathbb{I}(S_t=s)\): equals 1 when the current state is \(s\), otherwise 0.

The value update is

$$\boxed{V(s)\leftarrow V(s)+\alpha\,\delta_t\,e_t(s)}$$ where \(\delta_t\) is the TD error.

Example

Consider a robot travelling through three states:

$$S_1\rightarrow S_2\rightarrow S_3$$

When the robot receives a reward at \(S_3\), the eligibility traces help assign credit to earlier visited states such as \(S_1\) and \(S_2\). The amount of adjustment depends on each state’s eligibility trace.

When the agent receives new rewards, TD(1) uses eligibility traces to distribute the resulting learning updates among the states visited earlier.

Important clarification: in episodic tabular prediction, conventional accumulating-trace TD(1) is closely related to Monte Carlo learning, but its intermediate online updates are not necessarily identical to ordinary Monte Carlo updates. Also, the discount factor \(\gamma\) causes past eligibility traces to decay even when \(\lambda=1\). TD(1) does not necessarily wait until the end of an episode to update values: the standard backward-view algorithm updates values during the episode, and its relationship with full Monte Carlo returns is most clearly seen through the forward-view interpretation.

Technical corrections

  • TD(1) is not always exactly identical to ordinary Monte Carlo learning during training, although they have a close theoretical relationship.
  • TD(0) is not generally a maximum-likelihood estimator. The maximum-likelihood (certainty-equivalence) interpretation applies to particular batch-learning settings, not to the ordinary one-step TD(0) update.
  • TD(0) may converge slowly in some environments, but a stochastic environment alone does not guarantee slow convergence.

Conclusion: TD(0) learns using the immediate reward and the next-state value, while TD(1) uses eligibility traces to distribute learning updates across previously visited states. Both are TD prediction methods, but they differ in how learning information is assigned to past states.

SARSA: on-policy TD control

SARSA (State–Action–Reward–State–Action) is a model-free, on-policy Temporal-Difference (TD) control algorithm used to learn and improve an action-selection policy. It estimates the action-value function \(Q(s,a)\) using the reward received and the Q-value of the next action selected by the current policy.

Key characteristics

  • Model-free: does not require a model of the environment.
  • On-policy: learns the action values of the policy currently being followed.
  • Value-based: maintains Q-values for state-action pairs.
  • TD learning: updates action values using immediate rewards and estimated future values.
  • Bootstrapping: uses the estimated Q-value of the next selected action.
  • Exploration: often uses an \(\varepsilon\)-greedy policy to balance exploration and exploitation.

Why is SARSA called on-policy?

In on-policy learning, the agent learns the value of the same policy it uses to select actions. If the agent explores with random actions, SARSA’s values include the effect of that exploration.

For example, a robot uses an \(\varepsilon\)-greedy policy to explore different routes. SARSA updates its Q-values based on the next action selected by that policy, including exploratory actions. This differs from Q-learning, which updates using the maximum estimated next-state Q-value.

Key difference.
  • SARSA: learns using the next action selected by the current policy.
  • Q-learning: learns using the highest estimated Q-value in the next state.

Working principle of SARSA

SARSA gets its name from the five elements involved in each update.

  1. State (\(S_t\)): the current state of the agent.
  2. Action (\(A_t\)): the action taken in the current state.
  3. Reward (\(R_{t+1}\)): the reward obtained after the action.
  4. Next state (\(S_{t+1}\)): the new state reached.
  5. Next action (\(A_{t+1}\)): the next action selected using the current policy.

SARSA uses these five elements to update the estimated Q-value.

SARSA update equation

SARSA update. $$\boxed{Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\left[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)\right]}$$ \(A_{t+1}\) is the action actually chosen by the current policy.
SymbolMeaning
\(Q(S_t,A_t)\)Current action-value estimate
\(\alpha\)Learning rate
\(R_{t+1}\)Immediate reward
\(\gamma\)Discount factor
\(S_{t+1}\)Next state

The expression inside the square brackets is the TD error.

$$\boxed{\delta_t=R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)}$$ Therefore, $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\,\delta_t$$ For a terminal next state, the next-action Q-value term is taken as zero.

SARSA algorithm

  1. Initialize Q-values: initialize \(Q(s,a)\) for all state-action pairs, commonly to zero.
  2. Start an episode: observe the initial state \(S_t\).
  3. Select an action: choose \(A_t\) according to the current policy, such as \(\varepsilon\)-greedy.
  4. Perform the action: execute \(A_t\), receive reward \(R_{t+1}\), and observe the next state \(S_{t+1}\).
  5. Select the next action: if the next state is nonterminal, select \(A_{t+1}\) using the current policy.
  6. Update the Q-value: update \(Q(S_t,A_t)\) using the SARSA equation. For terminal transitions, use zero as the next-state contribution.
  7. Move on: set \(S_t\leftarrow S_{t+1}\) and \(A_t\leftarrow A_{t+1}\).
  8. Repeat: continue until the episode ends, and repeat for many episodes to improve the Q-value estimates and the policy.

Numerical example of SARSA

Robot moving through a grid

Suppose \(Q(S_t,A_t)=10\) and \(R_{t+1}=5\). The next action selected by the current policy has \(Q(S_{t+1},A_{t+1})=8\). Let \(\alpha=0.1\) and \(\gamma=0.9\).

$$Q_{\text{new}}=10+0.1[5+0.9(8)-10]=10+0.1[5+7.2-10]=10+0.1(2.2)$$ $$\boxed{Q_{\text{new}}=10.22}$$

Therefore, the estimated Q-value increases from 10 to 10.22.

Important: SARSA uses the Q-value of the next action selected by the policy, even if another action has a higher Q-value.

Example: SARSA in gridworld

Consider an agent moving through a grid to reach a goal while avoiding obstacles. Assume the following reward structure:

  • Reaching the goal: +10
  • Each ordinary move: −1
  • Entering an obstacle cell: −10 and the episode ends

The agent uses an \(\varepsilon\)-greedy policy to choose actions. At each step, SARSA updates its Q-value using the reward and the Q-value of the next action selected by that policy. Over repeated episodes, the agent can learn a route to the goal while accounting for the possibility of exploratory moves.

Advantages of SARSA

  1. Model-free: does not require an explicit environment model.
  2. On-policy learning: learns values for the policy actually followed during training.
  3. Online updates: updates Q-values after each transition.
  4. Exploration-aware learning: accounts for the effects of exploratory actions in value estimates.
  5. Simple implementation: tabular SARSA is relatively easy to implement for small, discrete environments.

Disadvantages of SARSA

  1. Exploration dependence: performance depends on the policy used to select actions.
  2. Sample inefficiency: may require many interactions to learn accurate values.
  3. Large state spaces: a Q-table becomes impractical when there are too many states or actions.
  4. Learning rate sensitivity: poor learning-rate selection can slow or destabilize learning.
  5. Optimality conditions: convergence to an optimal policy requires suitable exploration and learning-rate conditions; it is not guaranteed for every fixed exploratory policy.

Conclusion

SARSA is a model-free, on-policy TD control algorithm that learns action values through interaction with the environment.

It updates the Q-value using the immediate reward and the estimated Q-value of the next action selected by its current policy.

The most important feature of SARSA is that it learns about the policy it actually follows, unlike Q-learning, which uses the best estimated next action in its update.

Q-learning: off-policy TD control

Q-learning is a model-free, off-policy Temporal-Difference (TD) control algorithm used to learn the best action to take in each state. It learns an action-value function \(Q(s,a)\), which estimates the expected cumulative future reward obtained by taking action \(a\) in state \(s\) and then following a suitable policy. The main objective is to learn the optimal action-value function \(Q^*(s,a)\) and derive an optimal policy, using the best estimated action in the next state (under suitable conditions).

Key characteristics

  • Model-free: does not require a model of the environment’s transition probabilities or reward function.
  • Off-policy: learns about the greedy target policy while actions can be selected using a different exploratory behavior policy.
  • Value-based: learns Q-values to determine which actions are better.
  • TD learning: updates Q-values using the immediate reward and estimated future Q-values.
  • Bootstrapping: uses estimated next-state action values to update the current Q-value.

Q-value and Q-table

What is a Q-value?

A Q-value represents the estimated cumulative future reward of taking a particular action in a particular state.

$$Q(s,a)$$

where:

  • \(s\): current state
  • \(a\): action selected
  • \(Q(s,a)\): estimated action value

A higher Q-value generally indicates a more desirable action.

What is a Q-table?

A Q-table stores the Q-values of all state-action pairs in a finite environment.

  • Rows represent states.
  • Columns represent actions.
  • Each cell contains \(Q(s,a)\).

Initially, all values may be set to zero. As the agent interacts with the environment, Q-values are updated based on rewards and estimated future action values.

After sufficient learning, the agent can select a greedy action using

$$\boxed{a^*\in\arg\max_a Q(s,a)}$$ where \(a^*\) is an action with the highest estimated Q-value in state \(s\).

Bellman optimality equation

The Bellman optimality equation describes the relationship between the optimal Q-value of a state-action pair and the optimal Q-values of possible next states.

$$\boxed{Q^*(s,a)=\mathbb{E}\left[R_{t+1}+\gamma\max_{a'}Q^*(S_{t+1},a')\mid S_t=s,A_t=a\right]}$$ where:
  • \(Q^*(s,a)\): optimal action value.
  • \(R_{t+1}\): immediate reward.
  • \(\gamma\): discount factor.
  • \(S_{t+1}\): next state.
  • \(\max_{a'}Q^*(S_{t+1},a')\): highest optimal Q-value in the next state.
  • \(\mathbb{E}\): expected value over possible environment outcomes.

Key idea: the optimal Q-value depends on the immediate reward and the expected discounted value of the best future action.

Q-learning update rule

Q-learning updates the estimated Q-value after observing each transition.

Q-learning update. $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\big[R_{t+1}+\gamma\max_a Q(S_{t+1},a)-Q(S_t,A_t)\big]$$

The key term is

$$\max_a Q(S_{t+1},a)$$

It represents the highest currently estimated action value in the next state.

\(\max_{a'}Q(S_{t+1},a')\)Maximum estimated Q-value of the next state

The expression inside the square brackets is the TD error for Q-learning.

$$\boxed{\delta_t=R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a')-Q(S_t,A_t)}$$ Therefore, the update can also be written as $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\,\delta_t$$ For a terminal next state, the future Q-value contribution is zero.

Importance of learning rate and discount factor

Learning rate (\(\alpha\))

  • Controls how strongly new information changes the Q-value.
  • A small learning rate produces smaller updates.
  • A large learning rate gives more importance to recent information.

Discount factor (\(\gamma\))

  • Determines the importance of future rewards.
  • If \(\gamma=0\), only immediate rewards are considered.
  • If \(\gamma\) is close to 1, future rewards receive greater importance.

Why off-policy? Q-learning is called off-policy because the agent can learn about an optimal greedy policy while following a different policy to collect experience. It involves two policies:

  • Behaviour policy: used to choose actions during learning, often \(\varepsilon\)-greedy.
  • Target policy: the greedy policy whose action values Q-learning aims to learn, \(\pi(s)\in\arg\max_a Q(s,a)\).

The agent keeps exploring, yet the values it learns are those of the greedy policy.

For example, a robot may explore different routes using an \(\varepsilon\)-greedy behavior policy. However, its Q-value update uses the highest estimated next-state action value, regardless of which action it will actually take next. This is the important difference between Q-learning and on-policy TD control methods such as SARSA.

Example: one Q-learning update

Let \(Q(S_t,A_t)=10\), \(R_{t+1}=5\), \(\max_aQ(S_{t+1},a)=12\), \(\alpha=0.1\), \(\gamma=0.9\).

$$Q_{\text{new}}=10+0.1[5+0.9(12)-10]=10.58$$

The value rises because the target (15.8) exceeds the old estimate.

Basic working of Q-learning

Consider a robot learning to find the shortest route to a destination.

  • Agent: the robot.
  • Environment: rooms or a grid containing different paths.
  • State: current location of the robot.
  • Action: move up, down, left or right.
  • Reward: feedback received after moving.
  • Goal: reach the destination while maximizing cumulative rewards.

The robot initially does not know which actions are best. It explores the environment, receives rewards and gradually learns which actions lead to better outcomes.

Q-learning process

Q-learning algorithm: step by step

  1. Initialize Q-values: create a Q-table and initialize the values, commonly to zero: \(Q(s,a)=0\).
  2. Observe the initial state: start the agent in an initial state \(S_t\).
  3. Select an action: choose an action using an exploration strategy such as \(\varepsilon\)-greedy.
  4. Perform the action: take action \(A_t\), receive reward \(R_{t+1}\), and observe the next state \(S_{t+1}\).
  5. Update the Q-value: apply the Q-learning update equation.
  6. Move to the next state: set the current state to the observed next state.
  7. Repeat: continue until the episode ends, then repeat across episodes to improve the Q-value estimates.

Continue training across episodes until the Q-values become sufficiently accurate or a stopping criterion is reached.

Policy extraction

After learning, select an action with the highest Q-value for each state.

$$\boxed{\pi(s)\in\arg\max_a Q(s,a)}$$

Using the learned policy

The agent uses the learned policy to select actions that aim to maximize expected cumulative future rewards.

Exploration and exploitation

Q-learning must balance two important activities.

  • Exploration: the agent tries different actions to discover better rewards. Example: a robot tries a new route even though it has previously used another route.
  • Exploitation: the agent selects the action with the highest currently estimated Q-value. Example: the robot selects the route that has produced the best results so far.

Epsilon-greedy (\(\varepsilon\)-greedy) strategy

The \(\varepsilon\)-greedy strategy balances exploration and exploitation.

  • With probability \(\varepsilon\), the agent chooses an action randomly.
  • With probability \(1-\varepsilon\), the agent chooses an action with the highest Q-value.

Interactive example

20%
Explore 20%Exploit 80%

Adjust ε to see how the agent divides action selection between exploration and exploitation. For example, when ε = 0.2, the agent uses random exploration 20% of the time and greedy action selection 80% of the time.

Exploration is important because the action with the highest current Q-value may not actually be the optimal action.

Numerical example of Q-learning

Consider a robot navigating a small environment containing three states.

Assume:

  • Reward for moving from A to B = 0
  • Reward for moving from B to G = 10
  • G is the terminal goal state
  • Learning rate \(\alpha=0.5\)
  • Discount factor \(\gamma=0.9\)
  • Initial Q-values are zero

Step 1: move from B to G

Initially, \(Q(B,\text{Right})=0\). Since G is terminal, its future value is zero.

$$Q_{\text{new}}(B,\text{Right})=0+0.5[10+0.9(0)-0]$$ $$\boxed{Q_{\text{new}}(B,\text{Right})=5}$$

Step 2: move from A to B

In a later episode, assume the agent moves from A to B after learning the Q-value for B. Given \(Q(A,\text{Right})=0\), \(R=0\) and \(\max_aQ(B,a)=5\):

$$Q_{\text{new}}(A,\text{Right})=0+0.5[0+0.9(5)-0]$$ $$\boxed{Q_{\text{new}}(A,\text{Right})=2.25}$$
StateActionInitial QUpdated Q
ARight02.25
BRight05.00

Initially, the robot does not know the value of either action. When it reaches the goal from B, the Q-value of moving from B to G increases. In a later episode, this learned value is used to improve the Q-value of moving from A to B. Thus, Q-learning gradually propagates reward information backward through visited state-action pairs using bootstrapping.

Advantages of Q-learning

  1. Model-free learning: does not require knowledge of the environment’s transition and reward functions.
  2. Off-policy learning: can learn about the greedy target policy while exploring through another policy.
  3. Simple implementation: tabular Q-learning is straightforward for environments with a small number of states and actions.
  4. Online learning: updates Q-values after every observed transition.
  5. Convergence: in finite tabular problems, Q-learning converges to optimal Q-values under suitable conditions, including sufficient exploration and appropriate learning rates.

Limitations of Q-learning

  1. Large Q-tables: storing Q-values for every state-action pair becomes difficult in large environments.
  2. Sample inefficiency: may require many interactions to learn accurate values.
  3. Exploration challenges: poor exploration can prevent the agent from discovering good actions.
  4. Continuous state spaces: ordinary tabular Q-learning cannot directly represent all possible continuous states.
  5. Learning stability: learning rates, reward structure and exploration strategies influence learning behavior.

For large or continuous state spaces, function approximation may be used instead of a Q-table.

Applications of Q-learning

Autonomous systemsLearning control strategies in simulation

Technical corrections

  1. Q-learning does not necessarily select the action with the highest Q-value during learning; it may select exploratory actions.
  2. Q-learning learns the optimal action-value function, from which an optimal policy can be derived. An action-value function is not itself a policy.
  3. Off-policy learning does not mean learning without a policy. It means that the behavior policy used to collect experience can differ from the target policy being learned.

Conclusion

Q-learning is an important model-free, off-policy Temporal-Difference control algorithm that estimates the action-value function using observed rewards and bootstrapped future values.

It learns through repeated interactions with the environment and gradually improves its estimates of which actions produce higher expected cumulative rewards.

For beginners, the essential concepts are Q-values, the Q-table, the Q-learning update equation, \(\varepsilon\)-greedy exploration and the distinction between on-policy and off-policy learning.

Expected SARSA

Expected SARSA is a model-free Temporal-Difference (TD) control algorithm that extends SARSA. Instead of one sampled next action, it uses the expected Q-value of all possible actions in the next state, a probability-weighted average under a target policy, rather than the Q-value of a single selected next action.

  • SARSA uses the Q-value of the next action selected by the current policy.
  • Q-learning uses the maximum estimated Q-value of the next state.
  • Expected SARSA uses the probability-weighted average of the Q-values of all possible next actions.

Expected SARSA can be used for both on-policy and off-policy learning, depending on the target policy used in its update.

Key characteristics

  • Model-free: does not require a model of the environment’s transition or reward functions.
  • TD learning: updates Q-values using immediate rewards and estimated future action values.
  • Expected value: uses a probability-weighted average of the Q-values of possible next actions.
  • Flexible policy learning: can perform on-policy or off-policy learning.
  • Reduced variance: removes the randomness associated with sampling a single next action from the TD target.
  • Bootstrapping: uses existing Q-value estimates to update the current Q-value.

Working principle

Consider an agent moving through a grid to reach a goal.

  1. The agent observes its current state \(s\).
  2. It selects an action \(a\) using a policy such as \(\varepsilon\)-greedy.
  3. The agent takes the action and receives a reward \(R\).
  4. It moves to the next state \(s'\).
  5. The agent calculates the expected Q-value of all possible actions in \(s'\), weighted by their selection probabilities under the target policy.
  6. It updates the current Q-value using the immediate reward and this expected value.

Expected SARSA update equation

Expected SARSA update. $$\boxed{Q(s,a)\leftarrow Q(s,a)+\alpha\left[R+\gamma\sum_{a'}\pi(a'\mid s')Q(s',a')-Q(s,a)\right]}$$ Expected SARSA can be on-policy or off-policy depending on which policy \(\pi\) is used in the expectation.
SymbolMeaning
\(Q(s,a)\)Current Q-value for state \(s\) and action \(a\)
\(\alpha\)Learning rate
\(R\)Immediate reward
\(\gamma\)Discount factor
\(s'\)Next state
\(\pi(a'\mid s')\)Probability of selecting action \(a'\) in state \(s'\) under the target policy
\(Q(s',a')\)Q-value of action \(a'\) in the next state
\(\sum_{a'}\)Sum over all possible actions in the next state

Expected Q-value

$$\boxed{E_\pi[Q(s',A')]=\sum_{a'}\pi(a'\mid s')Q(s',a')}$$ This represents the weighted average of the Q-values of all possible actions in the next state.

The TD error for Expected SARSA is

$$\delta=R+\gamma E_\pi[Q(s',A')]-Q(s,a)$$

Therefore,

$$\boxed{Q(s,a)\leftarrow Q(s,a)+\alpha\,\delta}$$ For a terminal next state, the expected future Q-value is zero.

Expected SARSA algorithm

  1. Initialize Q-values: initialize the action-value function \(Q(s,a)\), commonly to zero.
  2. Start an episode: observe the initial state \(s\).
  3. Select an action: choose action \(a\) using a behavior policy such as \(\varepsilon\)-greedy.
  4. Execute the action: take action \(a\), receive reward \(R\), and observe the next state \(s'\).
  5. Calculate the expected Q-value: if \(s'\) is nonterminal, calculate \(E_\pi[Q(s',A')]=\sum_{a'}\pi(a'\mid s')Q(s',a')\).
  6. Update the Q-value: apply the Expected SARSA update equation. Use an expected next-state value of zero for a terminal state.
  7. Move to the next state: set \(s\leftarrow s'\).
  8. Repeat: continue until the episode ends, then repeat over many episodes to improve the Q-values.

Numerical example of Expected SARSA

Consider an agent in a gridworld. The next state has three possible actions with the following Q-values and selection probabilities.

Next actionQ-valueSelection probability

Right20.1

Let \(Q(s,a)=6\), \(R=4\), \(\alpha=0.1\), \(\gamma=0.9\).

Step 1: expected Q-value

$$E_\pi[Q(s',A')]=0.6(10)+0.3(5)+0.1(2)=6+1.5+0.2$$ $$\boxed{E_\pi[Q(s',A')]=7.7}$$

Step 2: TD error

$$\delta=4+0.9(7.7)-6=4+6.93-6$$ $$\boxed{\delta=4.93}$$

Step 3: update Q-value

$$Q_{\text{new}}(s,a)=6+0.1(4.93)$$ $$\boxed{Q_{\text{new}}(s,a)=6.493}$$

Therefore, the estimated Q-value increases from 6 to 6.493.

Expected SARSA with an ε-greedy policy

Expected SARSA commonly uses an \(\varepsilon\)-greedy policy. Under \(\varepsilon\)-greedy action selection:

  • With probability \(\varepsilon\), an action is selected randomly.
  • With probability \(1-\varepsilon\), a greedy action is selected.

When there is one greedy action among \(n\) available actions, its total selection probability is

$$\boxed{P(\text{greedy action})=1-\varepsilon+\frac{\varepsilon}{n}}$$

For each non-greedy action,

$$\boxed{P(\text{non-greedy action})=\frac{\varepsilon}{n}}$$ Here, \(n\) is the number of available actions.

If several actions tie for the highest Q-value, their greedy-selection probabilities must be handled according to the tie-breaking rule.

On-policy and off-policy Expected SARSA

Expected SARSA supports both types of learning.

On-policy Expected SARSA

The target policy used to calculate the expected Q-value is the same policy used to select actions. For example, an agent selects actions using \(\varepsilon\)-greedy and calculates the expected Q-value using that same \(\varepsilon\)-greedy policy.

Off-policy Expected SARSA

The behavior policy and target policy are different. For example, an agent explores using \(\varepsilon\)-greedy but calculates the expected Q-value using a greedy target policy. If the target policy is greedy, the expectation becomes

$$\sum_{a'}\pi(a'\mid s')Q(s',a')=\max_{a'}Q(s',a')$$

In this case, the Expected SARSA update becomes the Q-learning update.

Advantages of Expected SARSA

  1. Reduced variance: uses the expected next-action value instead of a randomly sampled next-action value.
  2. More consistent updates: reduces the effect of randomness in next-action selection.
  3. Flexible learning: can operate as an on-policy or off-policy method.
  4. Model-free: learns without requiring a model of environment dynamics.
  5. Potentially efficient learning: reduced variance may improve learning efficiency in suitable environments.

Disadvantages of Expected SARSA

  1. Higher computation: requires calculating a weighted average over possible next actions.
  2. Action probabilities required: needs the target policy’s action-selection probabilities.
  3. Large action spaces: calculating the expectation may become expensive when many actions are available.
  4. No universal performance guarantee: Expected SARSA is not always faster or more stable than SARSA in every learning environment.

Easy way to remember:

  • SARSA uses the next selected action.
  • Q-learning uses the best estimated next action.
  • Expected SARSA uses the weighted average of next actions.

Conclusion

Expected SARSA is a model-free TD control algorithm that updates action values using the probability-weighted average of Q-values for all possible next actions.

It reduces the randomness associated with selecting a single next action in ordinary SARSA. It can be used for both on-policy and off-policy learning, depending on the target policy.

Key point for examinations: SARSA uses the selected next action, Q-learning uses the maximum next-action Q-value, and Expected SARSA uses the expected Q-value of all possible next actions.

n-Step Bootstrapping

Bootstrapping in reinforcement learning

Bootstrapping. A technique in which an agent updates the estimated value of a state or state-action pair using existing estimates of future values, instead of waiting for the complete return of an episode. In simple words, bootstrapping means improving one estimate using another estimate.

Key features

  1. Uses estimated future values to update current values.
  2. Allows learning without waiting until an episode ends.
  3. Supports incremental or online learning.
  4. Is commonly used in Temporal-Difference (TD) methods.
  5. Forms the basis of algorithms such as TD(0), SARSA and Q-learning.

Example

Consider a robot moving from state A to state B. The robot receives an immediate reward of 5, and the estimated value of state B is 10. Instead of waiting until the robot reaches its final destination, bootstrapping uses the reward and the estimated value of B to update the value of A.

One-step bootstrapping

One-step bootstrapping updates the value of a state using the immediate reward and the estimated value of the next state (the TD(0) update from section 4). For a terminal next state, \(V(S_{t+1})=0\).

Types of bootstrapping

One-step: one observed reward followed by an estimated value of the next state. Example: TD(0) prediction.

$$G_{t:t+1}=R_{t+1}+\gamma V(S_{t+1})$$

Multi-step: rewards collected over several steps before bootstrapping from an estimated future value. For example, the two-step return is

$$G_{t:t+2}=R_{t+1}+\gamma R_{t+2}+\gamma^2V(S_{t+2})$$

Multi-step bootstrapping provides a connection between one-step TD learning and Monte Carlo methods.

Monte Carlo vs TD bootstrapping

Key difference: Monte Carlo learning waits for the complete outcome, while TD bootstrapping uses current estimates of future outcomes to learn earlier.

Advantages of bootstrapping

  1. Online learning: value estimates can be updated without waiting for an episode to end.
  2. Memory efficiency: one-step TD methods do not need to store complete trajectories.
  3. Continuing tasks: suitable for tasks that continue indefinitely.
  4. Use of partial experience: learning can occur from short sequences of experience.
  5. Flexible application: used in prediction and control algorithms.

Limitations of bootstrapping

  1. Estimation bias: incorrect future-value estimates can affect current updates.
  2. Error propagation: errors may be passed backward through successive updates.
  3. Learning-rate sensitivity: poor learning-rate choices can lead to slow or unstable learning.
  4. Convergence conditions: bootstrapping does not guarantee convergence in every setting, especially with function approximation.

n-Step bootstrapping

Definition. n-Step bootstrapping is a reinforcement learning technique in which an agent uses rewards obtained over the next \(n\) steps, followed by an estimated future value, to update its current value estimate. It is an extension of one-step TD learning.
  • 1-step TD: one observed reward and the estimated value after one step.
  • 2-step TD: two observed rewards and the estimated value after two steps.
  • 3-step TD: three observed rewards and the estimated value after three steps.
  • n-step TD: \(n\) observed rewards and the estimated value after \(n\) steps.

Illustration of n-step bootstrapping

General n-step return

n-step return. For a nonterminal trajectory over the next \(n\) steps: $$\boxed{G_{t:t+n}=R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{n-1}R_{t+n}+\gamma^nV(S_{t+n})}$$ or, equivalently, $$G_{t:t+n}=\sum_{k=1}^{n}\gamma^{k-1}R_{t+k}+\gamma^nV(S_{t+n})$$ Where:
  • \(G_{t:t+n}\): n-step return.
  • \(R_{t+1},\ldots,R_{t+n}\): rewards received during the next \(n\) steps.
  • \(\gamma\): discount factor.
  • \(V(S_{t+n})\): bootstrapped value after \(n\) steps.
If the episode terminates before \(n\) steps, only the remaining observed rewards are included; the terminal bootstrap value is zero.

n-Step TD prediction

Definition. n-Step TD prediction is an extension of TD(0) that estimates the state-value function using rewards collected over multiple steps and an estimated future-state value. Instead of updating from only the next reward, it uses an n-step return. The update is $$\boxed{V(S_t)\leftarrow V(S_t)+\alpha\big[G_{t:t+n}-V(S_t)\big]}$$ The quantity \(G_{t:t+n}-V(S_t)\) is the n-step prediction error.

Working steps

  1. Initialize the state-value function \(V(s)\).
  2. Select and follow a fixed policy \(\pi\).
  3. Observe the current state \(S_t\).
  4. Collect rewards over the next \(n\) steps, or until the episode terminates.
  5. Calculate the n-step return.
  6. Update the current-state value using the n-step return.
  7. Continue learning from the observed experience.

Example: two-step TD

Let \(R_{t+1}=4\), \(R_{t+2}=6\), \(V(S_{t+2})=10\), \(\gamma=0.9\), \(V(S_t)=12\), \(\alpha=0.1\).

$$G_{t:t+2}=4+0.9(6)+0.9^2(10)=4+5.4+8.1=17.5$$ $$V_{\text{new}}(S_t)=12+0.1(17.5-12)=12.55$$

Example: three-step TD prediction

Suppose a robot receives three rewards \(R_{t+1}=2\), \(R_{t+2}=3\), \(R_{t+3}=4\). The estimated value after three steps is \(V(S_{t+3})=10\). Let \(\gamma=0.9\), \(\alpha=0.1\), \(V(S_t)=8\).

$$G_{t:t+3}=2+0.9(3)+(0.9)^2(4)+(0.9)^3(10)=2+2.7+3.24+7.29$$ $$\boxed{G_{t:t+3}=15.23}$$ $$V_{\text{new}}(S_t)=8+0.1(15.23-8)=8+0.723$$ $$\boxed{V_{\text{new}}(S_t)=8.723}$$

Therefore, the estimated value of the initial state increases from 8 to 8.723.

Advantages of n-step TD prediction

  1. Uses multiple observed rewards before bootstrapping.
  2. Can propagate delayed reward information more quickly than one-step TD.
  3. Provides a way to balance bootstrapping bias and return variance.
  4. Does not require a complete episode when the n-step horizon is reached before termination.
  5. Connects one-step TD learning with Monte Carlo prediction.

Limitations of n-step TD prediction

  1. Must wait for up to \(n\) steps before updating an earlier state.
  2. Requires storing enough recent transitions or rewards.
  3. Larger \(n\) may produce higher-variance targets.
  4. The best choice of \(n\) depends on the environment and learning problem.

n-step SARSA

An on-policy control method that uses \(n\) rewards and the action value after \(n\) steps.

n-step SARSA. $$G_{t:t+n}=\sum_{k=1}^{n}\gamma^{k-1}R_{t+k}+\gamma^nQ(S_{t+n},A_{t+n})$$ $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\big[G_{t:t+n}-Q(S_t,A_t)\big]$$ For \(n=1\), this is the ordinary SARSA update.

Advantage: reward information propagates back across several state-action pairs faster than with one-step SARSA.

Off-policy and importance sampling

Off-policy learning means learning about a target policy while collecting experience with a different behavior policy. Let:

  • \(\pi\): target policy, which the agent wants to evaluate or improve.
  • \(b\): behavior policy, which generates the actual actions.

When \(\pi\) and \(b\) differ, some n-step methods use importance sampling to correct for the difference.

Importance sampling ratio

For n-step off-policy SARSA, the importance sampling ratio can be written as

$$\boxed{\rho_{t+1:t+n-1}=\prod_{k=t+1}^{t+n-1}\frac{\pi(A_k\mid S_k)}{b(A_k\mid S_k)}}$$

The corresponding update is

$$\boxed{Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\,\rho_{t+1:t+n-1}\big[G_{t:t+n}-Q(S_t,A_t)\big]}$$

This requires the behavior policy to assign nonzero probability to actions that the target policy may select in the relevant states.

Limitations

  • Ratios can become very large.
  • Large ratios raise the variance of updates.
  • Learning can turn unstable, especially on long trajectories.
  • Multiplying many ratios adds computation.
11

n-step tree backup

Tree backup is an off-policy method that uses expected action values under the target policy instead of importance sampling ratios. At each step it combines the reward from the sampled action with the values of the other actions, weighted by target-policy probabilities, which forms a tree-like backup.

One-step target. $$G_{t:t+1}=R_{t+1}+\gamma\sum_a\pi(a\mid S_{t+1})Q(S_{t+1},a)$$ the same target as Expected SARSA.

For several steps, within the horizon \(h=t+n\):

$$G_{k:h}=R_{k+1}+\gamma\Big[\sum_{a\ne A_{k+1}}\pi(a\mid S_{k+1})Q(S_{k+1},a)+\pi(A_{k+1}\mid S_{k+1})\,G_{k+1:h}\Big]$$

At the horizon \(G_{h:h}=Q(S_h,A_h)\) if the state is nonterminal; terminal branches stop without bootstrapping. The update is

$$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\big[G_{t:t+n}-Q(S_t,A_t)\big]$$

Here \(G_{t:t+n}\) is the tree-backup target, not the ordinary n-step SARSA return.

  • Advantages: no importance sampling ratios, can learn from another policy’s experience, uses information about alternative actions, avoids huge weights.
  • Limitation: expectations over actions can be expensive when the action space is very large.

  • Games: Model-free algorithms such as DQN have been used to learn Atari video games directly from experience. AlphaGo, however, is not a purely model-free example because it also uses search and planning.
  • Autonomous Vehicles: Model-free RL can be used to train driving decision policies in simulation. Real-world deployment requires extensive safety validation.
  • Healthcare: RL can be researched for sequential treatment planning and adaptive decision support. Clinical applications require careful safety and effectiveness evaluation.

Conclusion

Temporal-Difference Learning is an important model-free reinforcement learning method that combines learning from experience with bootstrapping.

It improves value estimates using the immediate reward and the estimated value of the next state, allowing learning without waiting for an entire episode to finish.

TD learning provides the foundation for important control algorithms such as SARSA, Q-learning and Expected SARSA.

Self-check

What is the TD error in TD(0)?

\(\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)\): the TD target minus the current estimate.

Why is SARSA on-policy and Q-learning off-policy?

SARSA bootstraps from the action the current policy actually takes next, so it learns that policy’s values. Q-learning bootstraps from the maximum next value, so it learns the greedy policy while behaving differently.

When does Expected SARSA equal Q-learning?

When the target policy in the expectation is greedy, since the weighted average then collapses to the maximum.

What problem does importance sampling solve, and what is its cost?

It corrects for the mismatch between behavior and target policies, but long products of ratios can be huge, giving high variance and instability.

How does tree backup avoid importance sampling?

It weights the values of all actions by their target-policy probabilities and continues only along the sampled action, so no ratios are multiplied.
