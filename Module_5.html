On-policy prediction with approximation

Introduction to function approximation

Function approximation is a technique in Reinforcement Learning (RL) used to estimate value functions or policies when the number of states or state-action pairs is very large or continuous.

In traditional tabular reinforcement learning, the agent stores the value of each state separately in a table. However, this becomes difficult when the environment contains millions of states or continuous variables such as position, speed and temperature.

Function approximation solves this problem by using a mathematical function with adjustable parameters to estimate the values of states.

Why is function approximation needed?

  1. Large state spaces: storing a separate value for every state requires excessive memory.
  2. Continuous state spaces: variables such as speed and position can have infinitely many possible values.
  3. Generalization: the agent can estimate values for states that it has not previously visited.
  4. Memory efficiency: a smaller set of parameters can represent many states.
  5. Real-world applications: useful in robotics, game playing and autonomous systems.

Example

Consider a robot navigating a room. Its state may include its position and speed. Since these variables can take many different values, storing the value of every possible state is impractical.

Instead, the agent learns a function that predicts the value of a state using these features.

On-policy prediction

Definition. On-policy prediction is the process of estimating the value function of a policy using experience generated by following that same policy. The objective is to estimate how good each state is when the agent follows the given policy.

The state-value function is

$$V^\pi(s)=\mathbb{E}_\pi[G_t\mid S_t=s]$$ Where:
  • \(V^\pi(s)\): true value of state \(s\) under policy \(\pi\).
  • \(\pi\): policy followed by the agent.
  • \(G_t\): total discounted future reward.
  • \(\mathbb E_\pi\): expected value while following policy \(\pi\).

Key features

  1. The agent follows a given policy to collect experience.
  2. It estimates the expected future rewards under that policy.
  3. It updates value estimates using observed rewards and transitions.
  4. It can use Monte Carlo or TD learning methods.
  5. It performs policy evaluation, not necessarily policy improvement.

On-policy prediction with approximation

On-policy prediction with approximation combines two ideas:

  • On-policy learning: learning about the policy currently being followed.
  • Function approximation: using a parameterized function instead of a table to estimate state values.

The estimated value function is represented as

$$\hat V(s,\boldsymbol{\theta})\approx V^\pi(s)$$ where \(\boldsymbol{\theta}\) represents the adjustable parameters of the approximating function.

Value-function approximation

Definition. Value-function approximation is a method of estimating the value of a state or state-action pair using a mathematical function instead of storing separate values in a table.

The function learns a relationship between state features and expected future rewards.

Types of value-function approximation

1. Linear function approximation. The estimated value is calculated as a weighted sum of state features.

$$\hat V(s,\boldsymbol{\theta})=\theta_0+\theta_1\phi_1(s)+\theta_2\phi_2(s)+\cdots+\theta_n\phi_n(s)$$

2. Nonlinear function approximation. A nonlinear model, such as a neural network, estimates state values using more complex relationships between features and values.

State-value vs action-value approximation

State-value approximationAction-value approximation
Estimates \(V(s)\)Estimates \(Q(s,a)\)

Advantages

  1. Reduces memory requirements.
  2. Handles large and continuous state spaces.
  3. Estimates values for unseen states.
  4. Allows learning from shared patterns among states.
  5. Can be implemented using linear models or neural networks.

The prediction objective

Definition. The prediction objective in reinforcement learning is to estimate the expected cumulative future reward of states or state-action pairs under a given policy.

With function approximation, the objective is to find parameters that make the estimated value function as close as possible to the true value function.

State-value prediction objective

The true state-value function is

$$V^\pi(s)=\mathbb E_\pi[G_t\mid S_t=s]$$

The function approximator predicts \(\hat V(s,\boldsymbol{\theta})\). The aim is to reduce the difference between these two values.

Mean squared value error

A common prediction objective is the Mean Squared Value Error (MSVE):

$$J(\boldsymbol{\theta})=\sum_s \mu(s)\left[V^\pi(s)-\hat V(s,\boldsymbol{\theta})\right]^2$$ Where:
  • \(J(\boldsymbol{\theta})\): prediction error objective.
  • \(\mu(s)\): weight assigned to state \(s\), often based on how frequently it is visited under the policy.
  • \(V^\pi(s)\): true state value.
  • \(\hat V(s,\boldsymbol{\theta})\): approximated state value.
  • \(\boldsymbol{\theta}\): parameters to be learned.

Goal: find parameters that minimize the prediction error.

In practice, the true value function is usually unknown. Therefore, learning methods use observed returns or bootstrapped targets to adjust the parameters.

Example

Suppose the true value of a state is 10, but the function approximator predicts 8. The squared error is

$$(10-8)^2=4$$

The learning algorithm adjusts the parameters to reduce this error.

Stochastic-gradient methods

Definition. Stochastic-gradient methods are optimization techniques that adjust the parameters of a function approximator using gradients calculated from individual samples or small batches of experience.

The main objective is to reduce prediction error by changing the parameters in a suitable direction.

Stochastic gradient descent (SGD)

SGD updates the parameters in the direction opposite to the gradient of a loss function.

$$\boldsymbol{\theta}_{t+1}=\boldsymbol{\theta}_t-\alpha\nabla_{\boldsymbol{\theta}}L(\boldsymbol{\theta}_t)$$ Where:
  • \(\boldsymbol{\theta}_t\): current parameters.
  • \(\alpha\): learning rate.
  • \(L\): loss function.
  • \(\nabla_{\boldsymbol{\theta}}L\): gradient of the loss with respect to the parameters.

Working of SGD

  1. Initialize the function parameters.
  2. Observe a state or sample.
  3. Calculate the predicted value.
  4. Calculate the prediction error.
  5. Compute the gradient.
  6. Update the parameters to reduce the error.
  7. Repeat using new experience.

SGD for value-function approximation

Suppose a sampled target return is \(U_t\). The squared-error loss can be written as

$$L_t(\boldsymbol{\theta})=\frac12\left[U_t-\hat V(S_t,\boldsymbol{\theta})\right]^2$$

Treating \(U_t\) as a fixed target, the gradient update is

$$\boldsymbol{\theta}_{t+1}=\boldsymbol{\theta}_t+\alpha\left[U_t-\hat V(S_t,\boldsymbol{\theta}_t)\right]\nabla_{\boldsymbol{\theta}}\hat V(S_t,\boldsymbol{\theta}_t)$$

This adjusts the parameters according to the prediction error and the sensitivity of the predicted value to each parameter.

TD prediction with function approximation

For one-step TD prediction, the TD error is

$$\delta_t=R_{t+1}+\gamma\hat V(S_{t+1},\boldsymbol{\theta}_t)-\hat V(S_t,\boldsymbol{\theta}_t)$$

The parameter update is

$$\boldsymbol{\theta}_{t+1}=\boldsymbol{\theta}_t+\alpha\delta_t\nabla_{\boldsymbol{\theta}}\hat V(S_t,\boldsymbol{\theta}_t)$$

This is called a semi-gradient TD(0) update, because the bootstrapped next-state target is treated as fixed when calculating the gradient.

Advantages of stochastic-gradient methods

  1. Can update parameters after observing a single sample.
  2. Does not require processing the entire dataset for each update.
  3. Suitable for large and continuous state spaces.
  4. Can be used with linear models and neural networks.

Limitations

  1. Gradients calculated from small samples may be noisy.
  2. Learning depends on the choice of learning rate.
  3. Large updates may cause instability.
  4. Function approximation and bootstrapping can introduce convergence difficulties.

Linear methods

Definition. Linear function approximation is a method in which the estimated value of a state is represented as a weighted sum of its features. The approximating function is linear in its adjustable parameters.

Linear value-function equation

$$\hat V(s,\mathbf w)=\mathbf w^T\boldsymbol{\phi}(s)$$ or $$\hat V(s,\mathbf w)=\sum_{i=1}^{d}w_i\phi_i(s)$$ Where:
  • \(\mathbf w\): weight vector.
  • \(\boldsymbol{\phi}(s)\): feature vector representing state \(s\).
  • \(w_i\): weight of feature \(i\).
  • \(\phi_i(s)\): value of feature \(i\).
  • \(d\): number of features.

Example

Consider a robot whose state is represented by two features: position = 2 and speed = 3. Suppose the weights are \(w_1=0.5\) and \(w_2=0.8\). The approximated value is

$$\hat V(s,\mathbf w)=w_1\phi_1(s)+w_2\phi_2(s)=0.5(2)+0.8(3)=1+2.4$$ $$\hat V(s,\mathbf w)=3.4$$

Therefore, the estimated value of the robot's state is 3.4.

TD(0) with linear function approximation

The TD error is

$$\delta_t=R_{t+1}+\gamma\mathbf w_t^T\boldsymbol{\phi}(S_{t+1})-\mathbf w_t^T\boldsymbol{\phi}(S_t)$$

Since the gradient of the linear value function is

$$\nabla_{\mathbf w}\hat V(s,\mathbf w)=\boldsymbol{\phi}(s)$$

the weight update becomes

$$\mathbf w_{t+1}=\mathbf w_t+\alpha\delta_t\boldsymbol{\phi}(S_t)$$

Thus, linear TD prediction updates the weights using the TD error and the feature vector of the current state.

Advantages of linear methods

  1. Simplicity: easy to understand and implement.
  2. Computational efficiency: requires relatively simple calculations.
  3. Low memory requirement: stores weights instead of a large value table.
  4. Interpretability: the weights indicate how the features contribute to the estimated value.
  5. Generalization: can estimate values for states not previously encountered.

Limitations

  1. Cannot easily represent complex nonlinear relationships with simple features.
  2. Performance depends on selecting suitable state features.
  3. May produce inaccurate estimates if important features are missing.
  4. Requires appropriate learning rates and feature scaling for effective learning.

Conclusion

On-policy prediction with function approximation is used to estimate the value function of a given policy in large or continuous state spaces.

Instead of storing a separate value for every state, the agent uses a parameterized function to predict state values.

Stochastic-gradient methods adjust the parameters to reduce prediction errors, while linear methods provide a simple and computationally efficient way to represent value functions using state features.

Key point: in tabular TD learning, the agent updates stored state values. In TD learning with function approximation, the agent updates the parameters of a function that estimates those values.

Eligibility traces

Introduction to eligibility traces

Definition. Eligibility traces are a technique in Reinforcement Learning (RL) used to assign credit to previously visited states or state-action pairs based on their contribution to future rewards.

They combine ideas from two important learning methods:

  • Monte Carlo (MC) methods: learn from complete episode returns.
  • Temporal-Difference (TD) methods: update value estimates using immediate rewards and estimated future values.

Eligibility traces allow the agent to update multiple previously visited states instead of updating only the current state.

Why are eligibility traces needed?

In ordinary TD(0) learning, only the value of the current state is updated after each transition. However, a reward received now may be related to several states visited earlier.

Eligibility traces help solve this credit assignment problem by allowing current learning updates to influence earlier states.

Example

Consider a robot moving through four states before receiving a reward.

Figure 1: Credit assignment using eligibility traces

When the robot receives a reward after visiting \(S_4\), eligibility traces help update earlier states such as \(S_1\), \(S_2\) and \(S_3\). Recently visited states generally have larger eligibility traces and receive stronger updates.

What is an eligibility trace?

An eligibility trace is a temporary record that indicates how strongly a state or state-action pair should be affected by the current learning update. The trace increases when the state is visited and gradually decreases over time.

Key concepts

  1. Eligibility: determines how strongly a state contributes to an update.
  2. Decay: eligibility traces decrease over time when states are not revisited.
  3. Credit assignment: allows learning updates to affect previously visited states.
  4. Memory of past visits: maintains a temporary record of recently visited states.
  5. Multi-step learning: helps information from later rewards influence earlier states.

Eligibility trace equation

For tabular TD learning with accumulating eligibility traces:

$$e_t(s)=\gamma\lambda e_{t-1}(s)+\mathbb I(S_t=s)$$
SymbolMeaning
\(e_t(s)\)Eligibility trace of state \(s\) at time \(t\)
\(e_{t-1}(s)\)Previous eligibility trace
\(\gamma\)Discount factor
\(\lambda\)Trace-decay parameter, between 0 and 1
\(\mathbb I(S_t=s)\)Equals 1 if state \(s\) is visited, otherwise 0

Explanation

  • When a state is visited, its eligibility increases.
  • When the state is not visited, its eligibility decreases by the factor \(\gamma\lambda\).
  • A state visited repeatedly may accumulate a larger eligibility trace.

Role of the λ parameter

The parameter \(\lambda\) controls how long information about previously visited states remains influential.

$$0\leq\lambda\leq1$$
λ valueEffect
λ = 0Only the current state receives the update, as in TD(0)
Small λPast eligibility traces decay rapidly
Large λPast eligibility traces decay more slowly
λ = 1Maximum trace persistence for a given γ; related to full-return learning in episodic tasks

Important: the actual trace-decay factor is \(\gamma\lambda\), not \(\lambda\) alone.

Numerical example of eligibility trace decay

Example

Suppose \(\gamma=0.9\) and \(\lambda=0.8\). The decay factor is

$$\gamma\lambda=0.9\times0.8=0.72$$

Assume the eligibility trace of a state is initially 1 after its first visit. If the state is not revisited, its trace decreases as follows.

The graph shows that eligibility decreases as time passes. Therefore, more recently visited states generally receive stronger influence from the current TD error.

The λ-return

The n-step return uses exactly \(n\) rewards before bootstrapping. The λ-return avoids choosing a single \(n\) by taking a weighted average of all n-step returns.

Definition. The λ-return is a geometrically weighted average of n-step returns, with weights that decrease by a factor of \(\lambda\) for each additional step. $$G_t^{\lambda}=(1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}G_{t:t+n}$$ where the n-step return is $$G_{t:t+n}=R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{n-1}R_{t+n}+\gamma^nV(S_{t+n})$$

In an episodic task that terminates at time \(T\), all n-step returns with \(t+n\ge T\) equal the ordinary return \(G_t\), so the λ-return becomes

$$G_t^{\lambda}=(1-\lambda)\sum_{n=1}^{T-t-1}\lambda^{n-1}G_{t:t+n}+\lambda^{T-t-1}G_t$$

Weights of the n-step returns

n-step returnWeight
\(G_{t:t+1}\)\(1-\lambda\)
\(G_{t:t+2}\)\((1-\lambda)\lambda\)
\(G_{t:t+3}\)\((1-\lambda)\lambda^2\)
\(\vdots\)\(\vdots\)
Full return \(G_t\) (episodic)\(\lambda^{T-t-1}\)

The weights add up to 1. Shorter returns receive larger weights.

Forward-view update

The offline λ-return algorithm updates the value using the λ-return as the target:

$$V(S_t)\leftarrow V(S_t)+\alpha\left[G_t^{\lambda}-V(S_t)\right]$$

This is called the forward view, because each state looks forward in time at the rewards that follow it. It needs the whole episode before the λ-return can be computed. TD(λ), with its eligibility traces, is the backward view: it approximates the same update online, using only the current TD error and the traces of past states.

Example: computing a λ-return

An episode ends after three rewards from time \(t\): \(R_{t+1}=1\), \(R_{t+2}=2\), \(R_{t+3}=3\). Let \(\gamma=0.9\), \(\lambda=0.5\), \(V(S_{t+1})=4\) and \(V(S_{t+2})=4\).

$$G_{t:t+1}=1+0.9(4)=4.6$$ $$G_{t:t+2}=1+0.9(2)+0.9^2(4)=6.04$$ $$G_t=1+0.9(2)+0.9^2(3)=5.23$$

With \(T-t=3\), the λ-return is

$$G_t^{\lambda}=(1-\lambda)\left[G_{t:t+1}+\lambda G_{t:t+2}\right]+\lambda^{2}G_t$$ $$G_t^{\lambda}=0.5\left[4.6+0.5(6.04)\right]+0.25(5.23)=3.81+1.3075=5.1175$$

The weights are 0.5, 0.25 and 0.25, which sum to 1.

Advantages and limitations

  • Advantage: one parameter \(\lambda\) smoothly balances bootstrapping (low variance, some bias) against full returns (no bootstrap bias, higher variance).
  • Limitation: the λ-return cannot be computed until the episode ends, so the forward view is not directly online.

TD(λ)

Eligibility traces in TD(λ)

Eligibility traces are commonly used in the TD(λ) algorithm. TD(λ) extends TD(0) by allowing learning updates to affect multiple previously visited states.

Step 1: calculate the TD error.

$$\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)$$ Where:
  • \(R_{t+1}\): immediate reward.
  • \(V(S_t)\): current-state value.
  • \(V(S_{t+1})\): next-state value.
  • \(\delta_t\): TD error.

Step 2: update eligibility traces.

$$e_t(s)=\gamma\lambda e_{t-1}(s)+\mathbb I(S_t=s)$$

Step 3: update state values.

$$V(s)\leftarrow V(s)+\alpha\delta_t e_t(s)$$ This update is applied to all states with nonzero eligibility traces, not just the current state. Here \(\alpha\) is the learning rate, \(\delta_t\) is the TD error and \(e_t(s)\) is the eligibility trace of state \(s\).

Eligibility traces with function approximation

When function approximation is used, state values are represented by a parameterized function \(\hat V(s,\boldsymbol{\theta})\). Instead of maintaining separate value estimates for every state, the agent updates the parameters \(\boldsymbol{\theta}\).

For accumulating eligibility traces:

$$\mathbf e_t=\gamma\lambda\mathbf e_{t-1}+\nabla_{\boldsymbol{\theta}}\hat V(S_t,\boldsymbol{\theta}_t)$$

The semi-gradient TD(λ) parameter update is

$$\boldsymbol{\theta}_{t+1}=\boldsymbol{\theta}_t+\alpha\delta_t\mathbf e_t$$

Eligibility traces now accumulate gradients associated with previously visited states. This allows function-approximation parameters to be updated using information from several earlier states.

n-step truncated λ-return methods

The ordinary λ-return looks arbitrarily far ahead, so it is unavailable until the episode ends. Truncating it at a finite horizon \(h\) gives a version that can be used online.

Definition. The truncated λ-return up to horizon \(h\) is a weighted average of the n-step returns that can be formed before time \(h\), with the remaining weight placed on the last return \(G_{t:h}\). $$G_{t:h}^{\lambda}=(1-\lambda)\sum_{n=1}^{h-t-1}\lambda^{n-1}G_{t:t+n}+\lambda^{h-t-1}G_{t:h}$$ For truncated TD(λ), the horizon is \(h=t+n\), so the update for \(S_t\) can be made at time \(t+n\): $$V(S_t)\leftarrow V(S_t)+\alpha\left[G_{t:t+n}^{\lambda}-V(S_t)\right]$$

Key ideas

  1. Only the next \(n\) rewards are used, so the update for \(S_t\) is delayed by \(n\) steps rather than by the length of the episode.
  2. The effect of \(\lambda\) is kept, because n-step returns shorter than \(n\) are still averaged.
  3. Only recent states and rewards need to be stored.
  4. For large \(n\), the truncated λ-return is close to the full λ-return.

Sarsa(λ)

Definition. Sarsa(λ) is an on-policy TD control algorithm that extends SARSA with eligibility traces. It keeps a trace for every state-action pair, so one TD error updates all recently visited state-action pairs.

Eligibility traces for state-action pairs

For accumulating traces:

$$e_t(s,a)=\gamma\lambda e_{t-1}(s,a)+\mathbb I(S_t=s,A_t=a)$$

The trace of the pair just visited increases by 1, and all other traces decay by \(\gamma\lambda\). All traces are set to zero at the start of each episode.

Sarsa(λ) update

The TD error is the SARSA error:

$$\delta_t=R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)$$

Every state-action pair is then updated in proportion to its trace:

$$Q(s,a)\leftarrow Q(s,a)+\alpha\,\delta_t\,e_t(s,a)\qquad\text{for all }s,a$$ For a terminal next state, \(Q(S_{t+1},A_{t+1})\) is taken as zero.

Sarsa(λ) algorithm

  1. Initialize \(Q(s,a)\) arbitrarily.
  2. For each episode, set \(e(s,a)=0\) for all pairs and observe the initial state \(S\).
  3. Choose \(A\) using a policy derived from \(Q\), such as \(\varepsilon\)-greedy.
  4. Take action \(A\), observe \(R\) and \(S'\), then choose \(A'\) from \(S'\) using the same policy.
  5. Calculate \(\delta=R+\gamma Q(S',A')-Q(S,A)\).
  6. Increase the trace of \((S,A)\) by 1.
  7. For all pairs, update \(Q(s,a)\leftarrow Q(s,a)+\alpha\delta e(s,a)\) and \(e(s,a)\leftarrow\gamma\lambda e(s,a)\).
  8. Set \(S\leftarrow S'\) and \(A\leftarrow A'\). Repeat until the episode ends.

Example: one Sarsa(λ) update

Let \(\gamma=0.9\), \(\lambda=0.8\), \(\alpha=0.1\) and suppose the TD error is \(\delta_t=2\). Three state-action pairs have been visited recently, with traces 1 (current), \(0.72\) (one step ago) and \(0.72^2\approx0.518\) (two steps ago).

PairTrace \(e\)Change \(\alpha\delta e\)
Current1.0000.1(2)(1.000) = 0.200
One step ago0.7200.1(2)(0.720) = 0.144
Two steps ago0.5180.1(2)(0.518) ≈ 0.104

The current pair receives the largest update, while earlier pairs still share in the credit.

Sarsa(λ) with function approximation

With a parameterized action-value function \(\hat Q(s,a,\mathbf w)\), the trace becomes a vector with the same size as \(\mathbf w\):

$$\mathbf e_t=\gamma\lambda\mathbf e_{t-1}+\nabla_{\mathbf w}\hat Q(S_t,A_t,\mathbf w_t)$$ $$\mathbf w_{t+1}=\mathbf w_t+\alpha\,\delta_t\,\mathbf e_t$$ where \(\delta_t=R_{t+1}+\gamma\hat Q(S_{t+1},A_{t+1},\mathbf w_t)-\hat Q(S_t,A_t,\mathbf w_t)\).

Advantages and limitations

  • Advantages: faster propagation of delayed rewards, online updates, on-policy learning of the policy actually followed.
  • Limitations: extra memory and computation for traces, sensitivity to \(\lambda\) and \(\alpha\), and care needed when combined with function approximation.

Sarsa(λ) is the control counterpart of TD(λ): TD(λ) estimates \(V\), while Sarsa(λ) estimates \(Q\) and improves the policy.

Advantages of eligibility traces

  1. Improved credit assignment: rewards can influence earlier visited states.
  2. Faster reward propagation: information from delayed rewards can reach earlier states more quickly.
  3. Online learning: value estimates can be updated after each transition.
  4. Flexible learning: the λ parameter controls the influence of past states.
  5. Combination of TD and MC ideas: connects one-step TD updates with longer-return learning.

Disadvantages of eligibility traces

  1. Additional memory: eligibility traces must be maintained for states or model parameters.
  2. Computational overhead: traces need to be updated at every step.
  3. Parameter tuning: choosing an appropriate λ value can be difficult.
  4. Learning instability: some combinations of bootstrapping and function approximation require care to ensure stable learning.

Conclusion

Eligibility traces are an important reinforcement learning mechanism that allows an agent to assign credit to previously visited states.

They maintain a temporary record of past states, with eligibility usually decreasing over time. By combining TD errors with these traces, algorithms such as TD(λ) and SARSA(λ) can update multiple states or model parameters.

Key point: TD(0) updates the current state's value, while eligibility traces allow the current TD error to influence previously visited states according to their trace values.

Policy gradient methods

Introduction to policy gradient methods

Definition. Policy gradient (PG) methods are reinforcement learning algorithms that directly learn and improve a policy by adjusting its parameters to maximize expected cumulative rewards.

Unlike value-based methods such as Q-learning and SARSA, which learn value functions and derive policies from them, policy gradient methods directly optimize the policy.

Key features

  1. Direct policy optimization: learns the policy directly instead of deriving it from a Q-table.
  2. Parameterized policy: represents the policy using adjustable parameters \(\boldsymbol{\theta}\).
  3. Gradient ascent: adjusts policy parameters in the direction that increases expected rewards.
  4. Stochastic policies: can select actions based on probabilities.
  5. Continuous action spaces: suitable for tasks involving continuous actions, such as robot speed and steering control.

Policy approximation and its advantages

Definition. Policy approximation is a technique in which a policy is represented using a parameterized mathematical function instead of storing a separate action-selection rule for every state.

The policy is expressed as

$$\pi_\theta(a\mid s)$$ Where:
  • \(\pi_\theta(a\mid s)\): probability of selecting action \(a\) in state \(s\).
  • \(s\): current state.
  • \(a\): action.
  • \(\theta\): policy parameters or weights.

Why is policy approximation needed?

  1. Large state and action spaces make tabular policies impractical.
  2. Continuous states and actions cannot be represented completely by finite tables.
  3. Parameterized functions allow generalization to unseen states.
  4. The policy can be optimized using gradient-based methods.

Types of policy approximation

1. Linear policy approximation. Uses a linear combination of features to calculate action preferences. A softmax function converts these preferences into action probabilities.

$$\pi_\theta(a\mid s)=\frac{\exp(\theta^T\phi(s,a))}{\sum_{a'}\exp(\theta^T\phi(s,a'))}$$ Here, \(\phi(s,a)\) represents features of the state-action pair.

2. Nonlinear policy approximation. Uses nonlinear models, such as neural networks, to represent more complex relationships between states and actions. For example, a neural network may receive a robot's position and speed and output probabilities for different actions.

Advantages of policy approximation

  1. Scalability: handles large and continuous state spaces.
  2. Memory efficiency: stores model parameters instead of a large policy table.
  3. Generalization: can select actions in previously unseen states.
  4. Smooth policy updates: gradually adjusts action probabilities.
  5. Stochastic exploration: supports probability-based action selection.

Working of policy gradient methods

The agent selects actions using the current policy, receives rewards, and adjusts policy parameters to improve future decisions.

The policy gradient theorem

Definition. The policy gradient theorem provides a mathematical expression for calculating how the expected return changes with respect to the policy parameters.

The objective is to maximize

$$J(\theta)=\mathbb E_{\pi_\theta}\left[\sum_{t=0}^{T-1}\gamma^tR_{t+1}\right]$$ where \(T\) is the episode length, \(\gamma\) is the discount factor and \(J(\theta)\) is the expected return.

A common policy gradient expression is

$$\nabla_\theta J(\theta)\propto\sum_s d^{\pi_\theta}(s)\sum_a Q^{\pi_\theta}(s,a)\nabla_\theta\pi_\theta(a\mid s)$$ where \(d^{\pi_\theta}(s)\) represents the appropriate state visitation weighting for the objective.

For Monte Carlo policy gradient estimation, a sampled-trajectory form is

$$\hat g=\sum_{t=0}^{T-1}\gamma^tG_t\nabla_\theta\log\pi_\theta(A_t\mid S_t)$$ where $$G_t=\sum_{k=t}^{T-1}\gamma^{k-t}R_{k+1}$$

For the discounted start-state objective shown above, the \(\gamma^t\) factor is included in this estimator.

Policy parameter update

Policy gradient methods use gradient ascent:

$$\theta_{\text{new}}=\theta_{\text{old}}+\alpha\nabla_\theta J(\theta)$$ Where:
  • \(\alpha\): learning rate.
  • \(\theta\): policy parameters.
  • \(\nabla_\theta J(\theta)\): gradient of expected return.

Gradient ascent is used because the objective is to maximize rewards, rather than minimize a prediction error.

REINFORCE: Monte Carlo policy gradient

Definition. REINFORCE is an on-policy Monte Carlo policy gradient algorithm that updates policy parameters using the returns obtained from complete episodes.

It directly improves a stochastic policy by increasing the probabilities of actions associated with favorable returns.

Key characteristics

  1. Model-free and on-policy.
  2. Directly optimizes the policy.
  3. Uses complete episode returns.
  4. Applies stochastic gradient ascent.
  5. Does not require a value-function approximator in its basic form.

REINFORCE update rule

Using an episode-based Monte Carlo policy gradient estimate:

$$\theta\leftarrow\theta+\alpha\sum_{t=0}^{T-1}\gamma^tG_t\nabla_\theta\log\pi_\theta(A_t\mid S_t)$$

REINFORCE algorithm

  1. Initialize the policy parameters \(\theta\).
  2. Generate an episode by following \(\pi_\theta\).
  3. Record states, actions and rewards.
  4. Calculate the discounted return \(G_t\) for each time step.
  5. Calculate the policy gradient estimate.
  6. Update the policy parameters using gradient ascent.
  7. Repeat over many episodes.

Advantages of REINFORCE

  • Simple and directly optimizes a policy.
  • Can handle stochastic policies.
  • Does not require an environment model.
  • Supports continuous-action policies.

Limitations

  • Requires complete episodes.
  • Gradient estimates can have high variance.
  • May require many episodes to learn effectively.
  • Learning can be slow when rewards are sparse or delayed.

REINFORCE with baseline

Definition. REINFORCE with baseline is an improvement to the basic REINFORCE algorithm that subtracts a baseline from the observed return to reduce the variance of policy gradient estimates. The baseline is commonly the estimated state-value function \(V(s)\).

Why is a baseline needed?

In ordinary REINFORCE, returns can vary significantly between episodes, causing noisy policy updates. A baseline provides a reference value for comparing how good the observed return is.

The difference between the observed return and baseline is

$$\hat A_t=G_t-b(S_t)$$ When \(b(S_t)=V(S_t)\), $$\hat A_t=G_t-V(S_t)$$ This is a sampled advantage estimate.

Example

Suppose the expected return from a state is 10.

Observed returnBaselineAdvantage estimate
1510+5
10100
710−3

A positive advantage indicates that the observed outcome was better than the baseline. A negative advantage indicates that it was worse.

REINFORCE with baseline update rule

$$\theta\leftarrow\theta+\alpha\sum_{t=0}^{T-1}\gamma^t\left[G_t-b(S_t)\right]\nabla_\theta\log\pi_\theta(A_t\mid S_t)$$

Advantages

  1. Reduces variance when a suitable baseline is used.
  2. Can produce more consistent policy updates.
  3. May improve learning efficiency.
  4. Helps distinguish better-than-expected and worse-than-expected outcomes.

Important: an action-independent baseline does not introduce bias into the expected policy gradient merely because the baseline is estimated. The baseline must not depend on the sampled action for the usual unbiasedness result.

Actor–critic methods

Definition. Actor–critic methods are reinforcement learning algorithms that combine policy gradient learning with value-function estimation.

They contain two main components:

  • Actor: learns the policy and selects actions.
  • Critic: estimates value functions and provides feedback to the actor.

Working of actor–critic

  1. The actor observes the current state.
  2. It selects an action using its policy.
  3. The environment provides a reward and next state.
  4. The critic evaluates the outcome using a value function.
  5. The critic calculates an error or advantage estimate.
  6. The actor improves its policy using this feedback.
  7. The process repeats.

Critic update

In a simple one-step actor–critic algorithm, the critic calculates the TD error:

$$\delta_t=R_{t+1}+\gamma V_\mathbf{w}(S_{t+1})-V_\mathbf{w}(S_t)$$

The critic updates its parameters using a semi-gradient TD rule:

$$\mathbf w\leftarrow\mathbf w+\alpha_c\delta_t\nabla_\mathbf w V_\mathbf w(S_t)$$

Actor update

The actor uses the critic's TD error as an advantage estimate.

$$\theta\leftarrow\theta+\alpha_a\delta_t\nabla_\theta\log\pi_\theta(A_t\mid S_t)$$ Here:
  • \(\alpha_a\): actor learning rate.
  • \(\alpha_c\): critic learning rate.
  • \(\delta_t\): TD error, used as feedback.
  • \(\theta\): actor policy parameters.
  • \(\mathbf w\): critic value-function parameters.

These are common one-step actor–critic updates; other actor–critic algorithms use different return and advantage estimators.

  • A2C: Advantage Actor–Critic, which uses advantage estimates to improve the actor.
  • A3C: Asynchronous Advantage Actor–Critic, which uses multiple parallel workers.
  • DDPG: Deep Deterministic Policy Gradient, developed for continuous control.

Conclusion

Policy gradient methods directly optimize a parameterized policy to maximize expected cumulative rewards.

Policy approximation makes it possible to learn action-selection strategies in large or continuous environments. The policy gradient theorem provides the mathematical foundation for adjusting policy parameters.

REINFORCE uses complete episode returns, REINFORCE with baseline reduces gradient variance using a reference value, and actor–critic methods combine policy learning with value-function estimation.

Key points for examinations.
  • Policy gradient methods optimize the policy directly.
  • REINFORCE uses Monte Carlo returns.
  • A baseline reduces gradient variance.
  • Actor–critic methods use an actor to select actions and a critic to evaluate them.

Self-check

Why is function approximation needed?

Tabular methods cannot store a separate value for every state when the state space is very large or continuous. A parameterized function uses far less memory and generalizes to states not yet visited.

What is the semi-gradient TD(0) update?

\(\boldsymbol\theta_{t+1}=\boldsymbol\theta_t+\alpha\delta_t\nabla\hat V(S_t,\boldsymbol\theta_t)\), where \(\delta_t=R_{t+1}+\gamma\hat V(S_{t+1},\boldsymbol\theta_t)-\hat V(S_t,\boldsymbol\theta_t)\). It is called semi-gradient because the bootstrapped target is treated as fixed when taking the gradient.

What is the gradient of a linear value function?

For \(\hat V(s,\mathbf w)=\mathbf w^T\boldsymbol\phi(s)\), the gradient with respect to \(\mathbf w\) is the feature vector \(\boldsymbol\phi(s)\), so the update becomes \(\mathbf w\leftarrow\mathbf w+\alpha\delta_t\boldsymbol\phi(S_t)\).

What does an eligibility trace record, and how does it decay?

It records how recently and how often a state or state-action pair was visited. It increases by 1 on a visit and otherwise decays by the factor \(\gamma\lambda\) each step.

What do λ = 0 and λ = 1 correspond to?

λ = 0 gives the one-step TD(0) update. λ = 1 corresponds to the Monte Carlo return in episodic tasks, with the trace decaying only through \(\gamma\).

How does truncated TD(λ) differ from the λ-return?

The λ-return needs the whole episode. The truncated version stops at a horizon \(n\), so an update can be made after \(n\) steps and only recent experience is stored.

How does Sarsa(λ) differ from SARSA?

SARSA updates only the current state-action pair. Sarsa(λ) keeps traces for all state-action pairs and updates each in proportion to its trace using the same TD error.

Why do policy gradient methods use gradient ascent?

The objective \(J(\theta)\) is expected return, which is to be maximized, rather than an error to be minimized.

Why does a baseline help REINFORCE, and why does it not add bias?

Subtracting \(b(S_t)\) reduces the variance of the gradient estimate. If the baseline does not depend on the sampled action, the expected gradient is unchanged.

What are the roles of the actor and the critic?

The actor holds the policy and selects actions. The critic estimates values and supplies the TD error, which the actor uses as feedback to update its parameters.
